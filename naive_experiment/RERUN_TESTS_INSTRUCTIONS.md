# Re-run Tests with Fixed Code

## Two Critical Bugs Fixed

### Bug 1: Hardcoded 640×480 Resize (FIXED ✅)
**Problem**: All scripts hardcoded output to 640×480, causing:
- 4:3 videos (740×555) → letterboxed
- 9:16 videos (480×854) → **stretched from portrait to landscape!**

**Fix**: Removed hardcoded resize from:
- `test_conditioning_debug.py`
- `baseline_inference.py`
- `finetuned_inference.py`

**Result**: Videos now output at native resolution from model (no distortion)

### Bug 2: SDEdit Disabled in Strong Conditioning (FIXED ✅)
**Problem**: `baseline_inference_strong.py` had `use_sdedit=False`, causing conditioning frames to be:
- Treated as "generated" frames
- Distorted/regenerated by the diffusion process
- Over-processed with high `image_cfg_scale=10.0`

**Fix**: Changed `use_sdedit=False` → `use_sdedit=True`

**Result**: Conditioning frames now stay **pixel-perfect** via SDEdit re-noising

   - ✅ Should be **pixel-perfect** copies of input video

2. **Generated frames (23-49)**:

   - Motion/scene should be coherent with conditioning

3. **Resolution**:
   - 4:3 config → 740×555 (slightly larger than 640×480)
   - 9:16 config → 480×854 (portrait, not stretched to landscape)
